# RutaSV · Demo en vivo

Abrir: `npm run dev` → **http://localhost:5173/presentacion.html** (pantalla completa con F11)

Se usa como una app normal, tocando o haciendo clic. Única tecla oculta: **R** = reiniciar (borra el viaje guardado).

## Buscar
1. **Buscar rutas** (los lugares ya vienen escritos)
2. Tocar la opción que votó el público → **Elegir esta ruta**
3. **Guardar** (lunes a viernes ya vienen marcados) → aparece en "Tus viajes"

## Calcular viaje
1. Hacer clic en el campo de hora y escribir **1000** y luego **a** (10:00 a. m.)
2. **Calcular** → "Sal a las 9:05 a. m."

## Avisos
- Tocar **Cierre en tu ruta** para ver la ruta alterna (volver con "← Avisos")
- **Ver ejemplo en pantalla** → baja la notificación; tocarla abre la ruta alterna
